# transformers 3.3.1 only requires torch>=1.11.0, so this is a safe bump.
# NOT bumped higher (2.9/2.10/2.13) on purpose: on linux/amd64 the DEFAULT PyPI torch wheel bundles

# via sentence-transformers `model.encode()` for embeddings, never torch.jit.script / lstm_cell /
# unpack_sequence / quantized modules / pad_packed_sequence. Those Dependabot alerts are dismissed as
# not-affected. Revisit if a lean CPU wheel + a version clearing them without CUDA bloat lines up.

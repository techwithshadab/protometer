Why an Embedded Vector Store, Not a Service
~100 chunks is a few hundred KB of numpy. Cosine over a 100 x 384 matrix is sub-millisecond, so a vector DB would add a container and a network hop for nothing. Neo4j does run as a service; the graph half genuinely benefits from a graph engine.

Observability: One Langfuse Trace Per Turn
Tracing is a safe no-op when unconfigured. It never changes an answer and never raises into the request path.

botox-chat-turn

Protected Input Only
The trace input is the tokenized message: surrogate tokens and an entity count, never raw values. (The "no cleartext PII" guarantee holds for DETECTED PII; the only user id is an anonymous localStorage token, no IP, no device data.) This is the per-turn DETAIL plane (Langfuse); a second OPERATIONAL plane scrapes the backend's /metrics endpoint into Prometheus + the Botox Grafana dashboard (turn rate/outcome, latency p50/p90/p99, PII-protection counters, grounding). Full KPI reference and both planes in observability.md.

Honest Scope: What Is and Isn't Protected
Protection is Protegrity, and mandatory: Discovery (ML/NER) detects the PII, the appython SDK tokenizes it. There is no mock and no regex fallback. If Discovery or the tokenizer is unreachable the bot fails closed, health reports not-ready and every turn refuses, so unprotected PII never reaches the model or the trace. Coverage is Discovery's coverage at the configured score threshold; a value it does not flag is not tokenized.

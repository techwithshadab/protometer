# Documentation

A short map. Each doc has one audience and one job.

| Doc | For | What it covers |
|---|---|---|
| **[SETUP.md](SETUP.md)** | anyone who clones the repo | Clone → running demo in ~10 min (no cloud account needed) + troubleshooting. |
| **[product-and-use-cases.md](product-and-use-cases.md)** | stakeholders, non-technical | What it is, who it's for, the three use cases, and the scope/assumptions/caveats. |
| **[architecture.md](architecture.md)** | engineers | The full technical deep-dive: end-to-end design, all seven stages, the model layer, observability, tech stack, invariants, and honest limitations. |
| **[demo-video-flow.md](demo-video-flow.md)** | whoever records the demo | The 15-20 minute demo walkthrough script. |
| **[results-aml.md](results-aml.md)** | reviewers | Generated results (never hand-edited; regenerated by `scripts/generate_results.py`). |
| **[protegrity-api-reference.md](protegrity-api-reference.md)** | engineers | Measured platform behaviours (burst limits, format sensitivity, element mappings). |
